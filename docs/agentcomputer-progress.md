**当前用户可见的切片**位于 AgentComputer“设置 → 连接”：macOS 本机可输入 `http://127.0.0.1:8090` 和现有 Octop 用户账号，查看盒子身份、能力及远端项目准备状态；iOS 真机需要可访问的 HTTPS 盒子地址。这里使用用户会话，尚无设备配对或远端任务执行。Octop 8088 的现有聊天页不会因服务端 API 增加而自动出现项目入口；当前 AgentComputer 的项目仍是本机数据，不能作为盒子端到端验收。

**下一个里程碑**是完成 M1 生产执行门禁，再把 AgentComputer 的新任务与消息交给盒子端 Task/Run。项目列表可读不代表项目 `ready`；当前 `projects.available=false`，不能把本地夹具称为远端任务已可用。

当前实施分支是 `feature/agentcomputer-foundation`，交付目标为 [RMinte/Octop](https://github.com/RMinte/Octop)。每轮在主[集成记录](agentcomputer-integration.md)中注明基线、改动、验证与剩余门禁。
