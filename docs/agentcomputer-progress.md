**用户可见的下一个里程碑**是 AgentComputer 显示盒子连接和远端项目状态，再把新任务与消息交给盒子端 Task/Run。Octop 8088 的现有聊天页不会因服务端 API 增加而自动出现项目入口；当前 AgentComputer 的项目仍是本机数据，不能作为盒子端到端验收。M2 客户端接线和 M1 生产执行门禁通过前，不把任何本地夹具称为远端任务已可用。

当前实施分支是 `feature/agentcomputer-foundation`，交付目标为 [RMinte/Octop](https://github.com/RMinte/Octop)。每轮在主[集成记录](agentcomputer-integration.md)中注明基线、改动、验证与剩余门禁。
